## Selected projects

### Reinforcement Learning from Human Feedback (RLHF) using PPO

**May – June 2026**

Fine-tuned a GPT-2 language model using Proximal Policy Optimization. Implemented a training pipeline covering dataset preprocessing, tokenization, response generation, reward computation, and policy updates, with reusable configuration, evaluation, and experiment utilities.

**Methods:** GPT-2 · RLHF · PPO · Language-model fine-tuning

[Explore the project](https://ayush-morya-portfolio.vercel.app/projects/gpt2-rlhf-ppo/)

### Electricity Demand Prediction Machine Learning Model

**January – March 2025**

Preprocessed five years of historical electricity-consumption data and engineered time-series features. Developed an XGBoost regression model to forecast hourly electricity demand and evaluated model outputs using RMSE and MAE.

**Methods:** XGBoost · Time-series preprocessing · Feature engineering · Model evaluation

[Explore the project](https://ayush-morya-portfolio.vercel.app/projects/electricity-demand/)

### End-to-End Catastrophe Risk Modeling & Stochastic Simulations

**January 2026 – Present**

Built an **Exposure → Hazard → Vulnerability → Financial Loss** pipeline to model insured loss potential across property exposures. Engineered an Exposure Data Module and serverless ETL using AWS Glue and PySpark. Implemented financial valuation using deductibles, policy limits, and coinsurance, generated Event Loss Tables, and applied stochastic simulation concepts.

**Tools & methods:** AWS Glue · PySpark · ETL · Financial valuation · Stochastic simulation

[Explore the project](https://ayush-morya-portfolio.vercel.app/projects/catastrophe-risk/)

### The Smart Vault – Cloud Cost Optimization — AWS

**September – October 2025**

Automated EC2 backup management using AWS Lambda and AWS CloudWatch. Designed serverless scheduling workflows for backup operations.

**Tools:** AWS Lambda · AWS CloudWatch · EC2

[Explore the project](https://ayush-morya-portfolio.vercel.app/projects/smart-vault/)
